## 🎓 HOW IT WORKS

```
1. User picks provider: npm run use:groq
2. .env.local updated: AI_PROVIDER=groq
3. Worker starts: npm run worker
4. Task loaded: From ./tasks/*.md
5. AI service called: callAI() function
6. Provider checked: process.env.AI_PROVIDER
7. Groq SDK used: Sends request
8. Response returned: Generated content
9. Files written: To ./repo/
10. Tests run: On generated code
11. Git commit: Changes saved
```
